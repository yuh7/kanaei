# かなえい (Kanaei)

<img src="assets/preview/app-256.png" width="88" align="right" alt="かなえい">

キーを**空打ち**するだけで IME を切り替える Windows の常駐アプリです。
**左のキーで英数、右のキーで日本語。** macOS の 英数 / かな キーと同じ操作感になります。

トグルではないので「今どっちだっけ」を気にせず押せます。
他のキーと組み合わせて押したときは切り替わらないので、`Alt+Tab` などはそのまま使えます。

## 入れる

Releases から `Kanaei.exe` を落として、好きなフォルダに置いて実行するだけです。
インストーラも、AutoHotkey のような追加のランタイムも要りません。

署名していない exe なので、初回に SmartScreen の警告が出ます。「詳細情報」→「実行」で進めてください。
気になる場合は自分でビルドしてください。必要なものは Windows に最初から入っています。

```bash
powershell -ExecutionPolicy Bypass -File build.ps1
```

## 使う

初回起動でウィザードが開くので、**使いたいキーを実際に押して**割り当てます。
押したキーがそのまま登録されるので、UHK や QMK のようにファームウェア側でキーを差し替えるキーボードでも確実です。

そのキーを空打ちしたときに Windows 側で何か起きるか（Alt ならメニューバーが開く、など）と、
かなえいがそれをどう打ち消すかも、キーを押したその場に出ます。

### タスクバー

アイコンが今の状態です。**左クリックでオン・オフ**が切り替わります。

| アイコン | 状態 |
| --- | --- |
| 黒地に `A` | 英数 |
| 青地に `あ` | 日本語 |
| 灰色の薄い `あ` | オフ |

Windows 11 はアイコンを既定で隠すので、右クリック →「**タスクバーに常に表示する**」を入れてください。

### 切り替えたときの表示

入力位置のそばに「あ」「A」が一瞬だけ出ます。タスクバーまで視線を落とさずに済みます。
新しい Microsoft IME では画面中央の切り替え通知が廃止されているので、その穴埋めです。
うるさければ右クリック →「切り替え時に「あ」「A」を表示」で切れます。

### 空打ちの副作用について

Alt を割り当てると本来はメニューバーが、Win ならスタートメニューが開きます。
かなえいはキーを離す直前に未使用のキーを挟んでこれを打ち消すので、Alt を割り当てても普段どおり使えます。
無変換・変換のようなキーは、そもそもアプリに渡さないので干渉しません。

## 切り替わらないアプリがあったら

手元では VS Code や Chrome のような Chromium / Electron 系でも切り替わっています。
それでも効かないアプリに当たったら、右クリック →「詳細 › **動作を記録する**」を入れて、
そのアプリで切り替えを試し、「記録を開く」で中を見てください。

```
切り替え 日本語 / アプリ=chrome / VK経路=成功 / メッセージ経路=成功 / 直後の状態=日本語
```

「直後の状態」が変わっていなければ、そのアプリには切り替えが届いていません。
設定ファイルの `UseVkImeOnOff` と `UseImeControlMessage` を片方ずつ `0` にすると直ることがあります。

## 設定

`Kanaei.ini`（exe と同じフォルダ）。右クリック →「詳細 › 設定ファイルを開く」で開けます。
項目ごとに説明が書いてあるので、中を見れば分かります。直したら「設定を再読み込み」で反映されます。

## やめる

右クリック →「詳細 › **登録を消して終了**」で、スタートアップ登録・タスクバーの設定・設定ファイル・記録をまとめて消します。
あとは exe を削除してください。

## 先行実装

同じことをするツールは前からあります。
**[karakaram/alt-ime-ahk](https://github.com/karakaram/alt-ime-ahk)**（AutoHotkey v1）が定番で、
左右 Alt の空打ちで切り替えるという発想も、未使用のキーを挟んでメニュー起動を打ち消す手法も、
もとはこちらのものです。他に
[alt-ime-rev](https://github.com/yuki0ueda/alt-ime-rev)（v2 フォーク）、
[ime-keys-for-us](https://github.com/tsuchim/ime-keys-for-us)（ネイティブ実装）があります。

かなえいが違うのは次の 3 点です。

- 使いたいキーを押して覚えさせられます。既存はどれも左右 Alt 固定で、変えるにはソースを書き換える必要があります
- 切り替えを TSF と IMM32 の両方に送ります。既存は IMM32 だけなので、UWP や Chromium 系で効く確率が上がります
- 空打ちかどうかの判定に、キーの一覧を使いません。既存は約 70 個のキーを列挙して判定しているので、
  マウスやテンキーとの組み合わせを取りこぼします
